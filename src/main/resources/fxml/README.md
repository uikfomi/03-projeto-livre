# 🪟 Telas FXML

Declara a estrutura visual das telas carregadas pelo JavaFX.

Mantenha as responsabilidades desta camada separadas das demais e consulte os arquivos relacionados antes de alterações.

## Explore as subpastas e arquivos

| Caminho | Conteúdo e responsabilidade |
|---|---|
| [.gitkeep](.gitkeep) | Marcador que mantém a pasta no controle de versão; não contém dados de aplicação. |
| [admin-dashboard.fxml](admin-dashboard.fxml) | Estrutura a navegação administrativa, incluindo o painel de status da loja. |
| [agenda-contatos.fxml](agenda-contatos.fxml) | Estrutura visual da agenda. |
| [cliente-vitrine.fxml](cliente-vitrine.fxml) | Estrutura a vitrine, o selo de funcionamento, o carrinho e o histórico de pedidos. |
| [login.fxml](login.fxml) | Estrutura visual de login e cadastro. |
| [README.md](README.md) | Guia de navegação e explicações desta pasta. |
| [selecao-modulos.fxml](selecao-modulos.fxml) | Estrutura visual da seleção de módulos. |

## Árvore estrutural comentada

O ponto inicial é `src/main/resources/fxml/`.

```text
src/main/resources/fxml/  # Declara a estrutura visual das telas carregadas pelo JavaFX.
├── .gitkeep  # Marcador que mantém a pasta no controle de versão; não contém dados de aplicação.
├── admin-dashboard.fxml  # Estrutura a navegação administrativa, incluindo o painel de status da loja.
├── agenda-contatos.fxml  # Estrutura visual da agenda.
├── cliente-vitrine.fxml  # Estrutura a vitrine, o selo de funcionamento, o carrinho e o histórico de pedidos.
├── login.fxml  # Estrutura visual de login e cadastro.
├── README.md  # Guia de navegação e explicações desta pasta.
└── selecao-modulos.fxml  # Estrutura visual da seleção de módulos.
```
